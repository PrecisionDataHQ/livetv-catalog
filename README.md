# LiveTV catalogue

Generated public channel metadata from iptv-org (CC0). Stream checks are manifest and first-segment checks, not playback or legal-clearance guarantees. No channel video is hosted, proxied or restreamed.

LiveTV does not host, sell or own any channel. It links to streams that broadcasters make publicly available. If you own a channel and want it removed, tell us and we remove it.

Removal contact is pending. Accepted requests add a channel identifier to removals.json within 24 hours. Never include requester details in this repository.
